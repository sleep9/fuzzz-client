# Security Policy

## Reporting a Vulnerability

Please do not report security vulnerabilities through public GitHub
issues.

If you believe you have found a security vulnerability in Fuzzz,
please report it privately through GitHub's Security Advisories or
contact the project maintainers directly at operations@fuzzz.cloud.

Please include:

- A description of the vulnerability
- Steps to reproduce
- The potential impact
- A proof of concept, if available

## Disclosure

Please allow the maintainers reasonable time to investigate and
address security issues before publicly disclosing them.

## Scope

Security reports involving authentication, cryptographic
verification, relay validation, malicious network data, data
integrity, or Chrome extension privileges are particularly relevant.
