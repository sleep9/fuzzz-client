# Contributing to Fuzzz

Thanks for your interest in contributing to Fuzzz.

Fuzzz is an open-source project, and contributions of all kinds are welcome,
including bug fixes, improvements, documentation, testing, and new features.

## Getting Started

### Requirements

- Node.js
- npm
- Git
- A Chromium-based browser for extension development

Some parts of the relay require additional native/build tooling. See the
project README for the current development setup.

### Fork and clone

Fork the repository, then clone your fork:

git clone https://github.com/sleep9/fuzzz-client.git
cd fuzzz
