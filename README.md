# Fuzzz
> The web was meant to be a conversation. The platforms turned it into a lecture —  they own the room, they own the record, they decide what gets remembered. Fuzzz takes the margin back. Your notes are  yours to sign, yours to keep, held by a network that no one company can silence.

 This is the repository for the <b>Fuzzz</b> client. A decentralized Chrome extension for leaving notes and drawings anywhere on the web, outside the boundaries of platform ownership and control. Your content lives on a federated network of [Gun.js](https://github.com/amark/gun) nodes, cryptographically signed by its owner and verifiable by anyone.

## Client Installation
To avoid googles distribution channels, Fuzzz must be installed manually using chrome developer mode. 

In a directory of your choice via terminal, run 
```git clone https://github.com/sleep9/fuzzz-client.git``` or download the [zip file](https://github.com/sleep9/fuzzz-client) and extract it.
- Go to chrome://extensions in the address bar.
- Toggle Developer mode in the top-right corner.
- Use Load unpacked to select the <i>/dist</i> folder within the extracted folder.

## Build Notes

Fuzzz uses proof of work for posts and verification, specifically
[Equi-X](https://github.com/tevador/equix).

Equi-X is a native library, so building Fuzzz requires Emscripten (`emcc`) to
generate the WebAssembly files. See `scripts/build-equix.sh` for details.

We use a snapshot of the Equi-X repository with additional wrappers
(`web.c` and `web.h`) included for the WebAssembly build.

## Limitations

Due to a design decision, Fuzzz does not use anchoring for notes or drawings. They are absolutely positioned. To preserve the user's intended position in the presence of reflow, they will only display at the resolution they were created at.
To compensate, the Fuzzz panel has standardized resolution options to select from and indicators in each cardinal direction. You can still leave notes at any resolution, but it is encouraged to run your browser at one of the Fuzzz resolutions to maximize usability.

## Fuzzz Relay

You can download the open source [Relay Code](https://github.com/sleep9/fuzzz-relay) and run it in your own Node.js environment.

Currently, Fuzzz uses a federated network secured by public keys to protect
against Sybil attacks. As such participation is currently permissioned.
If you would like to run a Relay, email [operations@fuzzz.co](mail://operations@fuzzz.co) with the subject <b>Relay Operations</b> and a public key generated by generate-pubkey.ts.

You are not limited to the default Fuzzz Network and can create
your own federation, though you will have to build your own client and relays from source as the peers are currently hardcoded.
